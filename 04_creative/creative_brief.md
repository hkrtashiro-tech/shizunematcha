## 1. 背景と目的

SHIZUNE MATCHAは現在、商品の白抜き画像とストックフォトを中心にビジュアルを構成している。しかし、プレミアム抹茶ブランドとしてのポジションを確立するには、ブランド独自のオリジナルビジュアルが不可欠である。

### 制作の目的

- ブランドの世界観（静けさ・品・現代的日本性）を視覚的に確立する
- Amazon / Shopify / SNS / 販促物を横断的にカバーするビジュアル群を整える
- ストックフォト依存から脱却し、ブランド固有の資産を構築する
- 商品の「本物感」「プレミアム感」を写真・デザインで裏づける

---

## 2. ブランドの世界観ガイドライン

### コアコンセプト

「慌ただしい日常の中で、静かに整う瞬間」

### ビジュアルのキーワード

- 静けさ（Stillness）
- 余白（Negative Space）
- 品（Elegance）
- 自然光（Natural Light）
- 現代的な日本性（Contemporary Japanese）
- ミニマル（Minimal）
- 温かみのあるニュートラルトーン（Warm Neutrals）

### 避けるべき表現

- 派手な色彩・ポップなデザイン
- 過度に伝統的な和風演出（鳥居、提灯、着物の記号的使用）
- スピリチュアル・ニューエイジ的な演出
- 安売り感、ディスカウント訴求のデザイン
- 過度にクリーンすぎて無機質な印象

### 参考イメージの方向性

- Aesop（空間・余白・素材感の見せ方）
- Blue Bottle Coffee（洗練されたミニマリズム）
- 中川政七商店（日本の伝統と現代性の融合）
- Ippodo Tea（茶の本物感と品格）

## 4. 撮影要件

### スタジオ環境

- 自然光が入るスタジオ or ロケーション
- 背景: 白壁、木目テーブル、コンクリート、石、リネンなどのニュートラル素材
- 人工的なライティングは補助のみ

### スタイリング

- 器: 日本製の茶碗（伝統的すぎず、現代的な作家物が理想）
- 茶筅、茶杓は本物を使用
- 小物: 最小限に抑える（花一輪、本、リネン程度）
- フード: 抹茶ラテ、抹茶スイーツ（撮影用に調理が必要）

### モデル

- 人物は必須ではないが、手元のみの登場はOK
- 使用する場合: 自然体、リラックスした雰囲気、多様性を考慮
- フルフェイスよりも手元・所作・空間の写真を優先

### カラーパレット

- ベース: ホワイト、アイボリー、ライトグレー、ベージュ
- アクセント: 抹茶グリーン（鮮やかすぎない）、ダークブラウン（木目）
- 避ける: ビビッドカラー、ネオン、ブラック主体

## 5. 納品形式

### 画像仕様

| 用途 | サイズ | 形式 | 備考 |
|------|--------|------|------|
| Amazon メイン画像 | 2000×2000px以上 | JPEG/PNG | 白背景、商品85%以上 |
| Amazon サブ画像 | 2000×2000px | JPEG/PNG | テキスト overlay可 |
| Amazon A+ | 970×600px 等 | JPEG/PNG | モジュール別 |
| Web ヒーロー | 1920×800px以上 | JPEG/WebP | レスポンシブ対応 |
| SNS (Instagram) | 1080×1080px / 1080×1350px | JPEG/PNG | — |
| ブログ用 | 1200×800px | JPEG/WebP | — |

### 納品フォルダ構成

```
deliverables/
├── product/          ← 商品単体（白背景含む）
├── lifestyle/        ← ライフスタイルカット
├── amazon/           ← Amazonサイズに加工済み
├── web/              ← Shopify / Web用
├── sns/              ← SNS用サイズ
├── brand_graphics/   ← A+、バナー、テンプレート
└── raw/              ← RAWデータ（アーカイブ用）
```
