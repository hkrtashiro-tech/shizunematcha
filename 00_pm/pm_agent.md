## 振り分けルール

Hikaruさんから指示を受けたら以下の順で判断する：

1. **どの領域の話か？** → 上記テーブルで該当フォルダを特定
2. **複数領域にまたがる場合** → 主担当を1つ決め、関連エージェントも参照
3. **優先タスクの確認** → 09_tasks/priority_tasks.md を参照
4. **不明点がある場合** → Hikaruさんに確認してから進める
