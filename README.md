---

## はじめに（Claude Codeでの使い方）

このプロジェクトはPMエージェントを中心に運用します。
Claude Codeを開いたら、そのまま指示を入力してください。
CLAUDE.mdが自動的にPMエージェントを起動します。

例：
- 「Amazonの運用を改善したい」
- 「Instagram投稿を作りたい」
- 「今日の優先タスクを確認したい」
