# 1. プロジェクトの全体像

## 1-1. プロジェクト名

**SHIZUNE MATCHA / 静音抹茶**

## 1-2. 事業主体

**Traverse Asia**

## 1-3. プロジェクトの性格

SHIZUNE MATCHAは、単なる抹茶販売ではなく、以下を兼ねるプロジェクトとして進行している。

- 日本発のプレミアム抹茶ブランド構築
- 海外向け越境EC事業
- Amazon / Shopifyを中心としたD2C販売
- 将来的に文化性・思想性・世界観を伴うブランド資産化
- 必要に応じてBtoB展開にも広げられる可能性

## 1-4. ブランドの基本思想

ブランドの中心にあるのは、「安さ」「お土産感」「和風記号の羅列」ではなく、以下のような世界観。

- 静けさ
- 余白
- 品
- 哲学性
- 現代的な日本性
- 慌ただしい日常の中の"整う瞬間"
- 派手さよりも、深い共感と美意識

英語圏では、いわゆる"Zenの借用"だけで浅く見せるのではなく、**contemporary Japanese premium brand** として設計する前提がある。

## 2-1. 基本ポジション

# 3. 主な対象市場

## 3-1. 最重要市場：アメリカ

現在、すでに販売を開始しているのはアメリカ。12月から実施している。

理由:
- Amazon USが既に主要チャネルとして稼働・検討されている
- 英語コンテンツや商品ページ、広告施策が先行している
- ブランド構築と販売実務の両面で、最も解像度が高い

## 3-2. 重点市場：シンガポール

シンガポールも重要市場として位置づけられているが、まだ販売に至っていない。

ただし、アメリカに比べると、具体的な販売設計、チャネル戦略、ローカルでの価格・物流・顧客獲得設計は、まだ詰め切れていない可能性がある。

## 3-3. 将来拡張の可能性

英語圏全般、中華圏、アジア主要都市圏への展開余地あり。イギリスやオーストラリアも検討中。
現時点では **まずUSを軸に収益とブランドの基盤を固める** ほうが合理的。

# 5. チャネル別の状況

## 5-1. Amazon US

### これまで議論されている内容

商品価格設定、クーポン設定、プロモーション設定、トラッキングID活用、キャンペーン設計、広告キーワード戦略、予算配分、入札戦略、ブランド/非ブランドキャンペーンの分け方、探索用キャンペーン設計、商品ページビジュアルの改善余地

### 現状認識

Amazonは既に稼働しているが、**最適化の余地が大きい状態**とみられる。

### 主な論点

- どの検索語に予算を寄せるべきか
- ブランドワードと一般ワードをどう分けるか
- 探索キャンペーンをどう設計するか
- CVR改善のために画像・コピー・A+をどう整えるか
- 値引き依存ではなく、ブランド価値を維持しながら売るにはどうするか

## 5-2. Shopify / 自社EC

### 把握していること

- アメリカ向けに月30〜100件程度の発送を想定
- Webサイトは既に存在
- 画像面やブランド表現面で未成熟
- 商品画像以外は外部フォトサイト依存の比重が高い

### 現状課題

- オリジナルクリエイティブ不足
- ブランドの世界観を自社資産で表現できていない
- まだ"借り物感"がある
- ECとしての説得力とブランド性の両立が必要

# 6. クリエイティブ / ビジュアルの状況

## 6-1. 現在の課題認識

- 白抜きの商品画像はある
- Web / Amazon / SNSで横断的に使えるビジュアル群が不足
- 外部ストックフォトの活用比率が高い
- Amazon画像もCanvaなどで補助的に作られた要素があり、完成度に限界がある

ブランドの"核となる見え方"がまだ完成していない。

## 6-2. すでに議論した方向性

外部のクリエイティブディレクターや制作会社へ発注し、Web / Amazon / SNS / 販促物 / ブランド全体のキービジュアルに使えるビジュアル制作を行う方向で議論済み。

### 必要になりうる工程

ビジュアルディレクション、撮影設計、スタイリング、アートディレクション、デザイン展開、Amazon / Web / SNS用のサイズ展開

## 6-3. 重要な示唆

ブランドの **ビジュアルシステム全体** として考える必要がある。何を撮るか、どういう空気感で見せるか、どこまで静けさを持たせるか、Amazonで売る実用性とブランドの美学をどう両立するか、まで設計する必要がある。
